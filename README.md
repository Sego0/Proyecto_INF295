# Pintando con Algoritmos 

Para la ejecucion de este avance de codigo ejecutaremos el codigo almacenado en el archivo "pruebas.cpp". En este podremos alterar el tamaño de el lienzo en **Canvas P(X, Y)** y la pintura objetivo **loadImageRGB_asCanvas("instancias/nombre_pintura.png", P);**.
Ahora para ejecutar el archivo debemos estar en al archivo raiz y ejecutar los siguientes comandos:

 ```bash
   make pruebas
  ./output/pruebas
```

Esto generar un archivo llamado **output1.cpp** en que se encontrara el lienzo con la imagen de solucion inicial.
